# Radar de Lançamentos SP

Mapa de satélite com os lançamentos imobiliários de São Paulo: estoque, preço de tabela e de fechamento.

- O site é publicado pelo GitHub Pages a partir desta pasta.
- Os dados ficam em `dados/lancamentos.json`. Cada empreendimento tem um `id`; o histórico de estoque e preço fica em `historico[id]`, do mais recente para o mais antigo.
- As atualizações são feitas pelo Claude a partir das apresentações da inteligência de mercado, de prints e de textos enviados no chat.
